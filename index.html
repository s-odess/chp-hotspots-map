Output Quality Evaluation Framework

Citizen · OpenAI Codex, macOS Shortcuts, Bash

Citizen's operations team began by listening to first-responder radio clips and writing notification copy by hand. Over time, language models took over the first draft, and the team reviewed each model-authored notification against two standards: empirical accuracy against the clip itself, and adherence to Citizen's editorial, style, privacy, and safety guidelines. I built an independent evaluation framework to measure how well those notifications met both standards.

I captured screenshots of more than 1,000 live outputs in real time, alongside my regular output and service-level obligations, audited each one against the standard, and defined concrete failure categories. A toolchain built with OpenAI Codex, macOS Shortcuts, and Bash turned the catalogue into a time-series graph of quality trends, which surfaced a 12% peak error rate. The findings reached leadership through my team and led to a leadership-backed recalibration of quality standards.

independent build source code on GitHub

CHP Dispatch Intelligence Pipeline

Independent · Python, Playwright, Gemini API, GitHub REST API

A Python pipeline that extracts live California Highway Patrol incident data from a legacy ASP.NET dispatch dashboard with Playwright. It opens each incident's detail page for the location and coordinates, then sends the records to the Gemini API, where a constrained prompt turns dispatch shorthand into plain-English summaries. The code retries on rate-limit and server errors, caps each run to protect the API quota, and publishes structured JSON to a public GitHub repository.

What I learned: the back end came together quickly, while the map front end I tried to build on top of it never worked, so I kept the pipeline and its JSON output. An earlier version captured the full dispatch log from each incident's detail page, and restoring that depth is my next step.

The pipeline runs from the command line, and the repository includes a GitHub Actions workflow. Source code and README.

Creators Program Launch

I volunteered for the Creators Program on my own initiative, entirely outside my service-level commitments and job description. The program became tied to Citizen's later B2B partnership with Axon.

For several months I served as the main contact for the program within the operations team and introduced the team to it. I put together most of the program guide, written with the head of marketing and the head of the consumer subscription team. I trained freelance video creators to tailor their footage to Citizen's editorial guidelines, trained the people on the creators team, and worked on launch procedures that readied the team for video-first. Because submitted video arrived without editorial context, I built the model-in-the-loop workflow described above to write the narrative around it.
